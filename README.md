# 拾光寫作｜國高中寫作題材庫

從命題用意、主題內涵、思辨與感受開始，逐步取材、成文與仿寫。

- 高中：知性在前，情意在後；59 個知性概念、52 張情意卡；知性 11 個主題（含身體與健康、科技倫理、藝術與文化）、情意 6 個主題。
- 111 則概念說明連貫交代主題內涵、關注理由、相關議題與希望帶動的思考、感受及關懷；與範文、寫作鷹架分開呈現。
- 每張概念卡附「他例＋己例」素材：知性每個概念 4 則可查證的真實他例（古典課文、歷史、科學、臺灣社會、國際時事、文學影視）與 2 組己例追問；情意每張卡 3 則作品或人物參照與 2 組己例追問。
- 17 個高中主題各有一篇完整篇幅示範：知性約 400 字（示範他例與己例並用）、情意約 650 字。
- 國中 27 個概念也有素材卡：每個 3 則課文、書籍或真實人物他例與 2 組己例追問。
- 「我的題材庫」：把他例、己例依主題存放，查看高中 17 個、國中 6 個主題的覆蓋情形，可匯出 Markdown；並整合情意工作台素材卡與整合備份。
- 單機版與班級版：題材庫預設是單機版（只存在自己的瀏覽器）。班級版 `class.html` 讓學生把素材加上〔拾光｜班級｜座號｜姓名｜主題｜他例/己例〕標記貼到老師開的 Padlet 觀摩牆（知性題、情意題各一面，按鈕依素材主題自動帶到對的那一面；每欄有主題引導卡與各概念提示卡），彼此觀摩；老師後台 `teacher.html` 填入兩面牆網址產生學生連結，匯入兩面牆匯出的 CSV，統計每人各主題的收集情形並匯出 Excel 用 CSV。
- 分工：首頁負責閱讀（概念說明、範文、主題練習），知性／情意工作台負責練寫與整理素材；全站使用同一套主題名稱。
- 國中：依題型與生活主題整理基測、會考作文。
- 20 個主題，每個主題 3 道原創題，共 60 題。
- 提供原創完整正文、逐段鷹架及本機草稿儲存與匯出。
- 官方原題、圖表與六級分樣卷索引另列來源；本站示範未經官方評級。

## 維護

使用 Node.js 執行，無須安裝第三方套件：

```sh
npm run build
```

原始資料、頁面與建置程式置於 `source/`，GitHub Pages 成品置於 `docs/`。重建會針對 GitHub 專案網址調整內部連結；圖片與資料檔皆隨網站部署。

草稿僅儲存在使用者瀏覽器，不送往伺服器。不同網站網址的本機紀錄不會自動同步，可在原站匯出後於新站匯入。
